==================================================
        MALTI SCOOTY CLASS - WEBSITE README
==================================================

Website Name: Malti Scooty Class (मालती स्कूटी क्लास)
Language: Hindi (Devanagari script)
Theme Color: Sky Blue (#00BFFF)

DIRECTORY STRUCTURE:
- index.html             (Home Page)
- about.html             (About Us Page)
- gallery.html           (Photo Gallery Page)
- videos.html            (Video Gallery Page)
- traffic-rules.html     (Traffic Rules Page)
- contact.html           (Contact Us Page)
- css/style.css          (Main Stylesheet)
- js/script.js           (Interactive JavaScript logic)
- images/                (Folder containing logo, sliders, and gallery images)
- videos/                (Folder for video placeholders)

HOW TO RUN LOCALLY:
1. Extract the "Malti-Scooty-Class-Website.zip" archive.
2. Open the folder structure.
3. Double-click on "index.html" to open the website directly in any modern browser.
